# Canvas-archiver
After graduating from UCF, I wanted to protect the course content I paid (so much money) to gain access to so that I could look them over again if I needed a refresher on course content.

## What does it do?
At it's current state, it reads through your course material and recursively downloads content depending on the current directory. I have seen successful results with a single course, so I would like to see how this goes for every course if I can get it to iterate through course codes :)
